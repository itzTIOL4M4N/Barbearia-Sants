# 💈 Barbearia Sants

Sistema web desenvolvido para modernizar o atendimento e o gerenciamento de uma barbearia, oferecendo uma experiência prática tanto para os clientes quanto para os profissionais.

O projeto busca facilitar o processo de agendamento de horários, a organização dos serviços e o acompanhamento das atividades da barbearia, por meio de uma interface moderna e responsiva.

## 🌐 Demonstração

- **Aplicação:** https://barbearia-sants.vercel.app/
- **Vídeo demonstrativo:** https://youtu.be/lZ7Xb1PVt6M

## 🎯 Objetivo do Projeto

Desenvolver uma plataforma para otimizar a gestão de uma barbearia, centralizando funcionalidades de atendimento e administração em um único ambiente.

A aplicação foi pensada para atender dois perfis principais:

- **Clientes:** facilidade para conhecer os serviços e realizar agendamentos.
- **Barbeiros e administradores:** organização dos atendimentos e acompanhamento das atividades do estabelecimento.

## ✨ Funcionalidades

- **Agendamento de horários:** organização dos atendimentos dos clientes.
- **Escolha de serviços:** visualização e seleção dos serviços oferecidos pela barbearia.
- **Gestão de clientes:** organização das informações dos clientes.
- **Gerenciamento de produtos:** possibilidade de apresentar e comercializar produtos.
- **Painel administrativo:** acompanhamento dos serviços realizados e das atividades da barbearia.
- **Controle financeiro:** proposta de acompanhamento de faturamento e resultados mensais.
- **Interface responsiva:** experiência adaptada para computadores e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| React | Construção da interface |
| TypeScript | Tipagem e organização do código |
| Vite | Ambiente de desenvolvimento e build |
| Tailwind CSS | Estilização da aplicação |
| Supabase | Integração com banco de dados e serviços de backend |

| React Router | Navegação entre páginas |

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- Git instalado.
- Gerenciador de pacotes npm.

### 1. Clone o repositório

```bash
git clone https://github.com/itzTIOL4M4N/Barbearia-Sants.git
```

### 2. Acesse a pasta

```bash
cd Barbearia-Sants
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Configure as credenciais necessárias para a integração com o Supabase, conforme as variáveis utilizadas pelo projeto.

### 5. Execute a aplicação

```bash
npm run dev
```

A aplicação estará disponível no endereço local informado pelo Vite no terminal.
